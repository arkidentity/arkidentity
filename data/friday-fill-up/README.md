# Friday Fill Up teaching notes

Optional. Each episode page shows the YouTube video description as its notes.
To replace that with longer notes, add `<videoId>.md` here (the ID from the
YouTube URL, e.g. `dQw4w9WgXcQ.md`). Supports `## headings`, `- lists`, `**bold**`.

Settings (Meet link, playlist ID, time) live in `lib/fridayFillUpConfig.ts`.
